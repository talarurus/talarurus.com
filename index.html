Featured product

Audit a repository before you depend on it.

Hammerhead is defensive security tooling for auditing potentially untrusted software repositories. It is local-first, written in Go, and reports findings in three separate classes.

Product overview

Hammerhead

Released v0.1.0 Go command-line tool Learn more

Local-first

Audits run on your own machine, where the repository already is.

SafeWalker architecture

Hammerhead is built around a security-focused SafeWalker architecture.

Security, Hygiene, Info

Hammerhead separates its findings into three classes: Security, Hygiene, and Info.

Terminal reports

Read results directly in your shell as part of a manual review.

JSON reports

Structured output for scripts and other tools.

Written in Go

A single command-line tool, used by hand or from your own automation.

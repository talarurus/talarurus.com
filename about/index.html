About Talarurus

An independent studio.
A clear purpose.

Talarurus builds software that is clear, useful, and easy to trust.

Founder

Ammaar Rehman founded Talarurus in 2026 to build security, developer, and local-first software.

The studio's first release is Hammerhead v0.1.0, a command-line tool for auditing potentially untrusted software repositories. Its next iteration is in development, alongside a personal finance dashboard and game projects.

The studio publishes documentation and examples for Hammerhead, including the tool’s capabilities and limitations.

Working principles

Built with care.
Run on your terms.

Clear behavior

Software should make its purpose, results, and limits understandable.

Local control

Your machine and your data should remain at the center of the experience.

Focused scope

A tool should have a defined job and do it well.

Honest expectations

The studio is clear about what is released, what is in development, and what its software can and cannot do.

The name

Talarurus is a genus of armored dinosaur. The name reflects the studio’s first focus on defensive software.

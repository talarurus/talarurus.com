GET STARTED

One command.

Hammerhead v0.1.0 is a command-line release for macOS and Linux. Review the release details and documentation before running your first audit.

Version and release details →

Verify the release

hammerhead version

Audit the current repository

hammerhead audit .

Write a JSON report

hammerhead audit . --output json > audit.json

Exit 1 means a Security finding reached the selected threshold. Hygiene and Info do not trigger finding-based failure.

THE SECURITY MODEL

Clear boundaries.
Honest expectations.

SafeWalker uses guarded reads and symlink containment checks. These are defense-in-depth measures, not a sandbox or a guarantee of safety.

Read the security model ↗
What v0.1.0 inspects

The current working tree, supported sensitive filenames and credential patterns, repository hygiene, and project context.

What it does not do

It does not scan Git history, validate active credentials, provide CVE database scanning, or perform semantic SAST analysis.

Coverage and limits

Exclusions, unreadable files, size bounds, partial traversal, and check failures can limit coverage. Exit 0 is a threshold result, not a guarantee of safety.

Summary

talarurus.com is a static informational website. It has no user accounts, no forms, no analytics, and no advertising. It does not intentionally use tracking pixels or set cookies. Contact happens by email only.

In this policy, "Talarurus", "we", and "us" refer to Talarurus, the operator of talarurus.com.

Scope

This policy covers the talarurus.com website. It does not describe how Talarurus software, such as Hammerhead, handles data. Refer to each project's own documentation for that.

What the website collects

The website itself does not ask for, store, or process personal information. Specifically, it does not use:

  • user accounts or sign-in;
  • contact or sign-up forms;
  • analytics software, advertising, or tracking pixels;
  • third-party scripts or embedded third-party content.

Fonts, styles, and scripts are served from talarurus.com itself. The site's one script is used only for interface behavior such as the mobile menu.

Hosting

This website is hosted on Cloudflare infrastructure. The infrastructure used to deliver and secure this site may process ordinary request metadata, such as IP address, request time, requested URL, and browser or network information, as part of operating the service.

Talarurus does not use this information to track or profile visitors.

Email

When you email Talarurus, we receive your email address, any information you choose to include in your message, and the technical details that normally accompany email.

We use this information to:

  • read and respond to your message;
  • investigate and follow up on security reports;
  • keep a record of correspondence where that is reasonably needed.

We do not sell this information, use it for advertising, or add you to mailing lists. It is shared only with the providers needed to send and store email, or where required by law.

Retention

Email is kept only for as long as it is reasonably needed for the purpose it was sent, such as resolving a question or a security report, or for as long as required by law. Request metadata processed by the hosting infrastructure is handled under that provider's own policies.

External links

This website links to other sites, such as GitHub. Those sites have their own privacy practices, which this policy does not cover.

Questions and requests

You can ask what correspondence we hold from you, or ask for it to be deleted, by emailing ammaar@talarurus.com.

Changes to this policy

If the website changes in a way that affects this policy, the policy will be updated on this page and the date above will change.
